# Corpus output snapshot (for review)

One tidy TSV per input in `tests/corpus/inputs/`, generated by running the
extract engine in `--generic` mode (same mode as `tests/corpus/expected/`)
followed by the tidy melt (`transform/melt.sh`). `_summary.tsv` lists, per
tool: winning strategy, confidence, and output column/row counts.

This directory is a **review snapshot**, not the golden regression set —
`tests/corpus/expected/` remains the CI-enforced goldens. Once reviewed,
accepted outputs can be promoted into `expected/` via
`tests/corpus/run.sh --update-golden` (see `tests/corpus/README.md`).

Regenerate with:

```bash
for f in tests/corpus/inputs/*.txt; do
    name="$(basename "$f" .txt)"
    wide="$(bash extract/envoy-extract --generic --emit-meta -f tsv --max-strategies 1 "$f" 2>/dev/null)"
    source transform/melt.sh
    _core_melt_tidy "$wide" > "tests/corpus/review-output/$name.tsv"
done
```
