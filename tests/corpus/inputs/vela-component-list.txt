NAME         DEFINITION-TYPE   DESCRIPTION
webservice   autodetects.core  Describes long-running, scalable, containerized services with a stable network endpoint.
worker       autodetects.core  Describes long-running, scalable, containerized services without a network endpoint.
task         autodetects.core  Describes jobs that run code or a script to completion.
cron-task    autodetects.core  Describes cron jobs that run code or a script to completion on a schedule.
