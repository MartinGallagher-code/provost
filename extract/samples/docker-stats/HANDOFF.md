# Handoff — samples/docker-stats

## Status: Complete

Sample input files for the `docker-stats` strategy (Docker stats container resource usage).

## Files

- `basic.txt` — docker stats with 3 containers (web-app, redis-cache, postgres-db): CPU, memory, net/block I/O, pids
- `single.txt` — docker stats with single container (nginx-proxy)
- `heavy.txt` — docker stats with high-usage containers (java-backend, elasticsearch, monitoring-agent)
